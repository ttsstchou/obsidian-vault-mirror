# Privacy

Vault Mirror runs entirely on the local filesystem of your macOS device.

- It does not send vault files, filenames, metadata, paths, or settings to any server.
- It does not authenticate with iCloud, Baidu Netdisk, or any other cloud service.
- It does not include analytics, telemetry, advertising, or accounts.
- Your existing desktop sync clients are responsible for their own network traffic and privacy practices.

The plugin stores its destination choice and the latest 20 sync history entries in Obsidian's plugin data file inside the source Vault.
