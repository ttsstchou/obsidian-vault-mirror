# Changelog

All notable changes to this project are documented in this file.

## 0.1.1

- Added a Simplified Chinese / English interface language selector.
- Localized the settings page and the sync preview, progress, and result dialogs.

## 0.1.0 — Initial release

- One-way macOS desktop mirror from the current Vault to a user-selected local destination.
- Live scan, plan preview, note-change count, file-change details, and progress UI.
- Safe create/update/delete ordering with staging, rollback, deletion safeguards, and path validation.
- Simplified Chinese plugin settings and sync UI.
- Source stability checks for desktop sync clients that are still changing files.
